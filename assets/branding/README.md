Three independently placed session cards represent the spatial canvas. A mint status light on the foreground card represents live session activity. The blue rounded-square tile and softly raised ivory cards echo the native macOS interface.

The user selected this blue session-cards image on 2026-10-25. [SessionCanvas.icns](SessionCanvas.icns) is its native macOS export: 16, 32, 128, 256, and 512-point representations at 1× and 2×, generated by resizing the unchanged PNG with `sips` and assembling it with `iconutil`. The app builder copies it to `Contents/Resources` and declares `CFBundleIconFile` before signing, for both local and release bundles. The source PNG is preserved; the other concepts are alternatives.

Generated with the built-in `image_gen` tool. The PNG preserves its transparent exterior.

## Generation prompt

Create one original production-quality macOS app icon concept for SessionCanvas, a native spatial workspace where users arrange existing AI coding sessions as independent notes on an infinite canvas. Output a SINGLE isolated app icon, large and centered, with a real transparent exterior, no presentation board, no mockup, no captions, no text, no letters, no watermark. The icon: a beautifully proportioned macOS rounded-square tile in rich clear cobalt blue with subtly darker blue at the bottom. Use refined satin material, a delicate bevel, gentle depth and soft lighting, crisp geometry. On the tile, three chunky softly rounded ivory-white session cards float separately in a spacious asymmetrical arrangement, a loose open C composition: a smaller card in upper left, a medium card in upper right slightly lower, and a wider foreground card in lower left/center. Each card has substantial thickness, subtly rounded edges and a gentle soft cast shadow, with consistent straight-on perspective, only slight rotation. One small vivid mint-green round status light at the top right corner of the foremost card. At most two short broad recessed blue-gray bars on each card, large and restrained enough to survive icon scaling, no tiny UI text. The arrangement must feel like movable notes distributed on a canvas, without connectors or network lines. Distinctive strong silhouette and lots of calm space, restrained blue/ivory/mint palette reflecting native Mac UI and live session status. Modern, tactile, professional developer-tool identity, polished like a carefully art-directed native macOS productivity app. Avoid excessive glass transparency, noisy gradients, neon glow, sparkles, robots, brains, code brackets, terminal symbols, checkmarks, desktop screens, extra tiny decoration. Square image composition. The rounded-square tile should occupy about 88 percent of the square image width, exterior transparent.

## Audit changes and remaining limits

Added source-connection as the seventh capability. Filled the previous requirement gaps for exact search/count scope, native input mappings, scale-dependent note details, project-summary urgency, supported transcript content/fallback, diagnostic probes, native URL validation, and source project ordering. Removed contradictory current-support claims from design/native guidance about backend project writes and the obsolete version-based move gate.

The implemented subset and the intended contract remain distinct. API-only real desktop project moves, atomic external-move protection, pending-operation recovery across restart, complete native/live workflows, real-host multipage/archive acceptance, last-known execution presentation, source-project removal, and actual draft release upload remain open as recorded in [Remaining acceptance gates](verification.md#remaining-acceptance-gates). A complete function inventory and strict OpenSpec validation do not close those gates.

For future features/corrections, update the capability's requirements/scenarios and this inventory row in the same task, then record actual verification in verification.md. Add a new row when a function introduces a new user action, observable state, integration boundary, or developer-facing operation.

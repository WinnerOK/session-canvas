This ledger covers all user corrections in the implementation conversation. Requirements are the behavioral contract; this file records where they are implemented and how they were checked. The last implementation run before this documentation audit passed **60 tests: 26 core and 34 runtime**. Parameterized tests count as one test with multiple cases. The run included opt-in installed-source checks and actual-server creation in an isolated home. Release compilation, bundle signature verification, and strict OpenSpec validation also passed. This documentation-only audit does not represent a new application test run.

The creation/handoff correction passed **63 tests: 26 core and 37 runtime**, including opt-in checks. The strengthened actual-server test first failed with RPC -32600 when an independent process tried to resume the new session while Canvas's inventory client remained connected. An isolated probe identified missing rollout persistence without a name and retained creator ownership despite unsubscribe. The implementation now always names the empty session and uses separate creation/verification children, awaiting both exits. The actual-server regression verifies independent resume, exact identity/name/membership, and zero turns for a named project session and a projectless session with blank name/folder. Native UI opening in the user's store remains unverified; no real-store test chat or model turn was created. Release packaging/signature and strict OpenSpec validation passed.

The subsequent creation-visibility and automatic-opening correction passed **67 tests: 26 core and 41 runtime**. The user's recording showed totals rising from 401 to 403 while Unknown was hidden. A model regression first reproduced a retained session with no visible note or selected viewer; an invalid-folder regression also exposed an error routed to a covered parent's alert. The fixed model temporarily reveals/focuses only the latest creation, preserves filters, displays errors inside the active form, and automatically dispatches its verified identity to Codex once. Tests press the actual SwiftUI submit button with native mouse events, verify preserved Unknown/search/project filters and refresh, inspect the exact injected native URL, suppress navigation on warnings, and exercise the ApplicationModel path against the isolated real server. Native capture exposed a further viewer-layout resize race; its regression verifies creation centering through resize without undoing a later user pan. The real server also confirms that normal inventory omits empty sessions even when exact-ID resume succeeds. One of the user's existing Canvas-created projectless test sessions was read and opened through native desktop navigation: its same identity changed from notLoaded to Idle with zero turns. This narrows the earlier native-opening gap; full external-URL/host workflow acceptance remains open.
